# Princess Dreamland

A fan-inspired website about Disney princesses (Frontend course, Assignment 5).

## Pages
- `index.html` - home page, princess cards, ratings, FAQ, newsletter
- `team.html` - our team
- `contact.html` - multi-step contact form

## Assignment 5 features
- Day / Night theme switch (menu button, saved in localStorage)
- Greeting by time of day (switch statement)
- Star rating on every princess card (querySelectorAll + classes)
- "Load More Princesses" button (fetch from `princesses.json`)
- Arrow-key navigation in the menu (keydown + switch)
- Multi-step contact form with Back / Next / Clear buttons (callback function)
- Objects, arrays, loops, filter / map / forEach
- Sound effects (Web Audio API) and CSS animations started by events

## Extra features (all options from the assignment)
- Read More button (style.display)
- Image gallery with thumbnails (changes the src of the big image)
- Greeting that uses the name entered by the user
- Random princess fact loaded with fetch (`facts.json`)
- Show Current Time button (toLocaleTimeString)
- Contact form sent with fetch POST and a callback function
- Magic Shop: filter products by category and price (switch)
- Princess News Feed: category buttons (switch)
- Language selector: English / Russian / Kazakh

## How to run
Open the website with GitHub Pages or a local server (for example VS Code "Live Server"),
because the "Load More Princesses" button uses `fetch`.
